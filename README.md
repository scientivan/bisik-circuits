# bisik-circuits

Compiled Arcium circuits (`.arcis`, Arcium 0.15.0) for the Bisik program on Solana devnet
(`aFNfbxfgBuQ6tr5qXDpTmTWrQ8hjLGYNEtdp2L7HjvD`). Arx nodes download these files and check each one
against the hash pinned in the program at build time.

These are build artifacts only. Source code will be published with the main Bisik repository.
